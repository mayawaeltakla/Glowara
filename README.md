# Glowara — غلوارا

مساحة هادئة وأنيقة لتنظيم العبادة والتخطيط والدراسة والعناية بالنفس، مبنية بـ **Flutter + Dart**، وتعمل على **Android والويب**، بالعربية والإنجليزية مع دعم RTL/LTR، وثلاث لوحات ألوان في الوضعين النهاري والليلي.

> **حالة التحقق:** يشغّل GitHub Actions (`.github/workflows/build.yml`) في كل دفعة إلى `main`: `flutter pub get` ثم `flutter analyze` ثم `flutter test` ثم بناء APK وبناء الويب، ويفشل التشغيل إن لم تنجح أي خطوة. راجع تبويب **Actions** لمعرفة نتيجة آخر تشغيل. وراجع قسم «ما لم يُنفَّذ» أدناه قبل اعتبار المشروع جاهزًا للنشر.

## ما الذي تم بناؤه في الكود؟

- **حساب محلي** بتسجيل ودخول وخروج، وكلمة المرور محفوظة كبصمة PBKDF2-HMAC-SHA256 (100,000 دورة) مع ملح عشوائي (وليس نصًا صريحًا). تُرقّى البصمات القديمة ذات الدورات الأقل تلقائيًا عند أول دخول ناجح.
- **الرئيسية**: ملخص يومي حقيقي للمهام والعادات والماء والدراسة والمزاج، مع تذكير ماء داخل التطبيق.
- **العبادات**: متابعة الصلوات الخمس، فتح المصحف، عدّ التسبيح والاستغفار، وتوضيح صريح لغياب نصوص الأذكار والدعاء.
- **القرآن**: جلب السورة من `api.alquran.cloud` بالنص العثماني، تخزينها محليًا بعد أول تحميل، واستعادة آخر سورة وآية.
- **المهام والتقويم**: إضافة/تعديل/حذف، تواريخ استحقاق، أولويات، تكرار (يومي/أسبوعي/أيام مخصصة)، وعرض المتأخرات. حالة الإنجاز مشتركة على مستوى سلسلة المهمة في هذه النسخة.
- **العادات**: جدولة يومية/أسبوعية/أيام مخصصة، تسجيل الإنجاز، وتحرير/حذف.
- **الدراسة**: مواد ووحدات/محاضرات، جلسات دراسة بمؤقت، ونسب تقدم حقيقية.
- **العناية والصحة**: روتين صباحي ومسائي، تتبع الماء، وملاحظات الوجبات.
- **المزاج والمذكرات**: تسجيل مزاج يومي، كتابة مذكرات، بحث، وحماية اختيارية برمز PIN محلي.
- **تعلم اللغة**: مجموعات بطاقات من إنشاء المستخدمة، اختبار اختياري مولّد من البطاقات نفسها، دروس نصية، وإحصاءات. لا يوجد منهج أو محتوى لغوي جاهز مضمّن.
- **التقدم**: إحصاءات محسوبة من السجلات الفعلية فقط، أهداف شهرية، وتقدم المواد. لا يوجد نظام شارات/إنجازات مستقل بعد.
- **الإعدادات**: اللغة، الثيم (وردي/ليلكي/رملي × نهاري/ليلي/النظام)، تفضيلات العرض، تذكير الماء وساعات الهدوء، PIN، تصدير/استيراد JSON عبر الحافظة، حجم التخزين، حذف البيانات، وحذف الحساب.

## التخزين والاستمرارية

- **sembast** هي طبقة التخزين المحلية:
  - Android: ملف `glowara.db` داخل مجلد المستندات عبر `path_provider`.
  - الويب: **IndexedDB** عبر `sembast_web`.
- كل قسم له مستودع مستقل (`lib/core/repositories/`) يفصل التخزين عن الواجهة.
- الترحيل من `shared_preferences` القديم غير هدّام: ينسخ البيانات مرة واحدة ويترك المفاتيح القديمة، عبر `lib/core/db/legacy_migration.dart`.
- التصدير يستبعد الحسابات وكلمات المرور ومفاتيح PIN، لكنه يشمل بيانات كل الحسابات المحلية على الجهاز.
- الاستيراد يتحقق من أنه ملف Glowara ومن إصدار المخطط وشكل كل السجلات قبل أي كتابة، ثم ينفّذ الكتابة داخل **معاملة واحدة** (إما أن تكتمل كلها أو لا يتغير شيء)، و**يعيد ربط السجلات بالحساب الحالي**، بما فيها مفاتيح الماء والمزاج والملف المركّبة. يجب إنشاء الحساب الحالي أولًا؛ الاستيراد لا يُنشئ حسابات ولا يستعيد كلمات المرور.
- تفضيلات الجهاز (اللغة، الثيم، التذكيرات، هدف الماء، PIN، وموضع القرآن/التسبيح) مشتركة بين الحسابات المحلية وليست لكل حساب.
- **لا توجد مزامنة سحابية** في هذه النسخة. الحساب محلي على الجهاز فقط، ولا يمكن تسجيل الدخول به على جهاز آخر.

## البدء السريع

```powershell
cd C:\path\to\glowara
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
.\tool\setup_windows.ps1 -InstallFlutter
```

أو يدويًا بعد تثبيت Flutter:

```powershell
flutter pub get
flutter analyze
flutter test
flutter run -d web-server --web-port 8080
```

التفاصيل الكاملة وخطوات بناء APK والويب في [`docs/INSTALL_WINDOWS.md`](docs/INSTALL_WINDOWS.md).

## هيكل المشروع

```text
glowara/
├── lib/
│   ├── main.dart                     # فتح قاعدة البيانات وتهيئة الحالة
│   ├── app.dart                      # MaterialApp، go_router، القوقعة ذات التبويبات
│   ├── core/
│   │   ├── db/                       # sembast + ترحيل البيانات القديمة
│   │   ├── models/                   # الموديلات الأساسية ونماذج الأقسام
│   │   ├── repositories/             # مستودع لكل قسم
│   │   ├── services/                 # خدمات الشبكة (القرآن)
│   │   ├── state/app_state.dart      # ChangeNotifier + InheritedNotifier
│   │   ├── theme/                    # اللوحات والثيمات
│   │   ├── localization/             # النصوص العربية والإنجليزية
│   │   ├── security/                 # PBKDF2 المشترك + PIN المحلي
│   │   ├── utils/                    # أدوات التاريخ
│   │   └── widgets/                  # عناصر الواجهة المشتركة
│   └── features/                     # شاشات الأقسام
├── test/core_test.dart               # اختبارات وحدات أساسية (لم تُشغَّل بعد)
├── docs/
│   ├── INSTALL_WINDOWS.md
│   ├── CONTENT_SOURCES.md
│   ├── STORAGE_AND_LIMITATIONS.md
│   └── FINAL_REPORT_AR.md            # تقرير التسليم وحالة التحقق
├── assets/icon/                      # مصدر الأيقونة والنسخة الجاهزة
├── tool/
│   ├── setup_windows.ps1
│   ├── generate_icons.py         # توليد أحجام الأيقونة
│   ├── apply_branding.py         # تطبيق الأيقونة والاسم على android/ وweb/
│   └── icons/                    # الأيقونات الجاهزة
├── pubspec.yaml
├── analysis_options.yaml
└── l10n.yaml                          # غير مستخدم حاليًا (التعريب مدمج)
```

مجلدا `android/` و`web/` **غير موجودين بعد**؛ ينشئهما سكربت الإعداد أو أمر `flutter create --platforms android,web .`. راجع التحذير في دليل التثبيت قبل تشغيل `flutter create` مباشرة.

التعريب مكتوب داخل `lib/core/localization/` ولا يعتمد على توليد ARB وقت التشغيل. ملفات `l10n.yaml` و`lib/l10n/*.arb` باقية كمرجع/أساس محتمل لاحقًا، لكنها **غير مستخدمة** حاليًا؛ لا تعدّلها وتتوقع ظهور النص في التطبيق.

## الأيقونة والهوية

- المصدر: `assets/icon/glowara_icon_source.png`. يولّد `tool/generate_icons.py` (يحتاج Pillow وnumpy) نسخة شفافة الزوايا `assets/icon/glowara_icon.png` وكل الأحجام في `tool/icons/` (Android mipmap، أيقونات الويب، نسخ maskable، favicon).
- `tool/apply_branding.py` ينسخ الأيقونات إلى `android/` و`web/` بعد توليدهما بـ `flutter create`، ويضبط اسم التطبيق وألوانه في `AndroidManifest.xml` و`web/manifest.json` و`web/index.html`. تستدعيه workflows البناء والنشر وسكربت `tool/setup_windows.ps1` تلقائيًا، ويمكن تشغيله يدويًا بأمان أكثر من مرة.
- لتغيير الأيقونة: استبدلي ملف المصدر ثم شغّلي `python3 tool/generate_icons.py` وارفعي الناتج.

## الاختبارات

- `test/core_test.dart`: أدوات التاريخ، وتسلسل JSON للموديلات، وحساب النسب، وإعدادات التذكير.
- `test/password_hasher_test.dart`: PBKDF2 مقابل متجهات اختبار معروفة، والمقارنة بزمن ثابت.
- `test/privacy_service_test.dart`: قفل PIN، والقفل المؤقت بعد المحاولات الخاطئة، وترقية الصيغة القديمة.
- `test/auth_repository_test.dart`: التسجيل والدخول وترقية البصمات، وحذف حساب واحد دون المساس بغيره.
- `test/local_database_test.dart`: التصدير والاستيراد الذري واستثناء الكاش والبيانات الحساسة.
- `test/quran_service_test.dart`: خدمة القرآن بعميل http وهمي (إعادة المحاولة، المهلة، الاستجابات التالفة).
- اختبارات الواجهة والتكامل **غير موجودة بعد**.
- تُشغَّل كل الاختبارات في CI مع `flutter analyze` وبناء APK والويب.

## ما لم يُنفَّذ بعد (بصراحة)

| البند | الحالة |
|---|---|
| مزامنة سحابية آمنة بين الأجهزة | غير منفذة. الحساب محلي فقط. |
| إشعارات خلفية (Android/ويب) | غير موصولة. تذكير الماء يظهر داخل التطبيق فقط عند فتح الرئيسية. |
| تذكيرات المهام/العادات/المذكرات | غير منفذة. لا توجد إشعارات مجدولة لهذه العناصر. |
| مواقيت الصلاة وحسابها | غير منفذة. التطبيق يتيح تسجيل الصلوات فقط. |
| شارات/إنجازات مستقلة | غير منفذة. قسم التقدم يعرض إحصاءات وأهدافًا شهرية فقط. |
| تقويم شهري كامل | غير منفذ. توجد أسبوعية مع منتقي تاريخ وعرض يومي، لا شبكة شهر كاملة. |
| منهج لغوي جاهز | غير مضمّن؛ المحتوى من بطاقات ودروس المستخدمة فقط. |
| تتبع غذائي/سعرات | ملاحظات وجبات فقط، وليست قاعدة أطعمة أو حساب سعرات. |
| نصوص الأذكار والدعاء | لا تُعرض من الذاكرة. تظهر رسالة «المصدر قيد الربط» إلى أن يُعتمد مصدر موثوق قابل للتحقق. |
| تشفير المذكرات | PIN قفل وصول محلي، وليس تشفيرًا للبيانات. |
| قفل المذكرات تلقائيًا | لا يُعاد القفل تلقائيًا عند مغادرة التطبيق أو الخروج من القسم؛ يبقى مفتوحًا حتى إعادة التشغيل/تغيير الحالة. |
| تصدير بيانات مستخدم واحد فقط | التصدير يشمل بيانات كل الحسابات المحلية على الجهاز (دون كلمات المرور). |
| إتمام كل تكرار مهمة على حدة | الإتمام على مستوى السلسلة؛ لا يوجد سجل إتمام لكل occurrence. |
| تفضيلات لكل حساب | اللغة/الثيم/التذكيرات/هدف الماء/PIN/موضع القرآن مشتركة على مستوى الجهاز. |
| استعادة كلمة المرور | غير متاحة؛ لا يوجد بريد تحقق أو خادم. |
| تغيير كلمة المرور | غير متاح من الإعدادات دون حذف الحساب. |
| تصدير/استيراد كملف | عبر الحافظة (Clipboard) فقط، لا منتقي ملفات. |
| اختبارات الواجهة والتكامل | غير موجودة. اختبارات الوحدات للخدمات والمستودعات موجودة (انظر «الاختبارات»). |

تفاصيل إضافية في [`docs/STORAGE_AND_LIMITATIONS.md`](docs/STORAGE_AND_LIMITATIONS.md).

## الأمان والخصوصية

- لا توجد مفاتيح سرية أو كلمات مرور مكتوبة في الكود أو المستودع.
- كلمة مرور الحساب لا تُخزَّن نصًا صريحًا، لكن **قاعدة البيانات المحلية غير مشفرة**.
- PIN المذكرات يُشتق بـ PBKDF2 ويُقفل التحقق 5 دقائق بعد 5 محاولات خاطئة متتالية. يمنع الفتح العابر داخل التطبيق فقط، ولا يحمي من الوصول إلى ملفات التطبيق على جهاز مفتوح.
- حذف الحساب يحذف الحساب الحالي وبياناته فقط؛ تُمسح تفضيلات الجهاز المشتركة فقط عند حذف آخر حساب.
- كاش سور القرآن لا يدخل في التصدير ولا في حجم التخزين المعروض.
- التصدير ملف JSON نصي غير مشفّر؛ لا تشاركه أو تخزّنه في مكان غير آمن. كما يبقى في الحافظة (Clipboard) بعد النسخ ويمكن لتطبيقات أخرى قراءته.
- الاستخدام الحقيقي على الإنترنت يحتاج HTTPS، ومراجعة أمنية مستقلة، وربطًا خلفيًا للمزامنة إن أُضيفت.

## المحتوى الديني

- القرآن من `api.alquran.cloud` (نص عثماني). يجب مراجعة النص والتشكيل والرسم قبل النشر العام.
- الأذكار والدعاء: **لم يُربط مصدرها بعد**، ولا يُعرض نص ديني غير متحقق منه.
- المصادر والسياسة الكاملة في [`docs/CONTENT_SOURCES.md`](docs/CONTENT_SOURCES.md).

## الترخيص والاسم

- «Glowara» اسم عمل مؤقت، والتوفر التجاري غير مؤكد.
- لا تُضف مفاتيح API أو أسرارًا إلى المستودع. استخدم متغيرات بيئة أو إعدادات نشر خارجية.
