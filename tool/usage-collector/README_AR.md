# جامع عدّ الاستخدام المجهول ولوحة المديرة

هذا المجلد يجعلك ترين **عدد المستخدمات الحقيقي** لغلوارا. فيه ثلاث قطع:

| الملف | ما هو |
|---|---|
| `worker.js` + `lib.js` + `schema.sql` + `wrangler.toml` | الجامع: خدمة صغيرة على Cloudflare (مجانية) تملكينها أنتِ |
| `dashboard.html` | لوحتك: صفحة تفتحينها أنتِ فقط لترين الأرقام |
| داخل التطبيق | بطاقة موافقة + مفتاح في الإعدادات، ويرسل رقمًا عشوائيًا مرة يوميًا |

## ما الذي يُجمع بالضبط
يرسل جهاز المستخدمة **التي وافقت فقط**، مرة في اليوم: معرّفًا عشوائيًا للتثبيت (لا يدل على حساب ولا شخص)، ونسخة التطبيق، والمنصة، واللغة (ar/en)، وتاريخ اليوم.
**لا يُرسل أبدًا:** اسمًا أو بريدًا أو مهامًا أو عادات أو مذكرات أو مزاجًا أو عبادة أو أي ملف أو موقع. والجامع لا يحفظ عناوين IP.

## مهم أن تعرفيه
- الأرقام تبدأ من يوم تشغيل الجامع **وتحديث المستخدمات للنسخة الجديدة ومواقفتهن**. لا يمكن عدّ من استخدمن التطبيق قبل ذلك.
- من لم توافق لا تُحسب. لذلك الرقم هو "عدد من وافقن"، وهو أقل من الواقع.
- الأرقام إرشادية وليست مضمونة ضد العبث (يمكن لشخص تقني إرسال إشارات مزيفة). للحماية الأقوى يمكنك لاحقًا تفعيل قواعد Rate Limiting في Cloudflare.
- **حدّثي نص الخصوصية** ليذكر هذا العدّ (انظري `docs/USAGE_COUNT_PRIVACY_AR.md`) قبل نشر نسخة تفعّله.

## خطوات النشر (أنتِ تفعلينها، ولن تعطيني أي كلمة سر أو رمز)
تحتاجين حاسوبًا فيه Node.js (النسخة 18 أو أحدث).

1. أنشئي حسابًا مجانيًا على <https://dash.cloudflare.com/sign-up>.
2. في الطرفية، من داخل هذا المجلد `tool/usage-collector`:
   ```
   npm install -g wrangler
   wrangler login
   ```
3. أنشئي قاعدة البيانات:
   ```
   wrangler d1 create glowara-usage
   ```
   سيطبع لك `database_id`. الصقيه في `wrangler.toml` مكان `PUT_YOUR_D1_DATABASE_ID_HERE` (المعرّف ليس سرًّا).
4. أنشئي الجدول:
   ```
   wrangler d1 execute glowara-usage --remote --file=schema.sql
   ```
5. اختاري رمز مديرة طويلًا عشوائيًا (٣٠ حرفًا فما فوق) واحفظيه في مدير كلمات المرور، ثم ضعيه كسرّ (سيطلب منك كتابته هو، ولا يُحفظ في أي ملف):
   ```
   wrangler secret put ADMIN_TOKEN
   ```
6. انشري الجامع:
   ```
   wrangler deploy
   ```
   سيعطيك عنوانًا مثل `https://glowara-usage.اسمك.workers.dev`.
7. جرّبي أنه حيّ: افتحي `dashboard.html` من حاسوبك (انقري عليه مرتين)، واكتبي العنوان والرمز، واضغطي «عرض الأرقام». ستري أصفارًا حتى تصل أول إشارة.
8. لتفعيل العدّ في التطبيق: ابنيه بإضافة هذا إلى أمر البناء (عنوان الجامع **ليس سرًّا**، فقط لا تضعي الرمز أبدًا في التطبيق):
   ```
   --dart-define=GLOWARA_PING_URL=https://glowara-usage.اسمك.workers.dev/ping
   --dart-define=GLOWARA_VERSION=1.0.0
   ```
   بدون هذا الإعداد يبقى العدّ **معطّلًا بالكامل** ولا تظهر بطاقة الموافقة.

## اختبار محلي (اختياري)
```
cd tool/usage-collector
npm test
```
يشغّل 14 اختبارًا للجامع (التحقق من الإشارات، حساب النشطات، رفض الطلبات الخاطئة، حماية الرمز).

## ما أستطيع وما لا أستطيع من جهتي
أنا كتبتُ الكود واختبرتُه (اختبارات للجامع، وتشغيل اللوحة في متصفح حقيقي أمام جامع محلي). لكني **لم أنشر الجامع على Cloudflare** لأنه حسابك أنتِ، ولم أجرّب العدّ على جهاز أندرويد حقيقي. حين تنشرينه وتبنين نسخة بالعنوان، جرّبي على هاتفك: وافقي على البطاقة، ثم افتحي اللوحة لترين "1".
