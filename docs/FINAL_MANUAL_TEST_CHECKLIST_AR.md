# قائمة الاختبار اليدوي قبل الإطلاق

**الحالات المسموحة فقط:** `Pending` (لم يبدأ) · `Passed` · `Failed` · `Not Tested`.
لا تُغيَّر خانة إلى `Passed` إلا بعد تنفيذ الخطوات فعليًا على الجهاز المذكور ويُسجَّل اسم المختبِرة والتاريخ والجهاز. **كل البنود الآن `Not Tested`**: لم يُجرَّب أي منها على جهاز حقيقي.

بيانات الجهاز (تُملأ عند الاختبار): الموديل ـ نسخة أندرويد ـ نسخة التطبيق ـ متصفح الويب.
